# Emil Kowalski UI/UX Style

Achieve extreme polish and fluidity in UI components.

## Implementation Details
1. **Micro-Interactions**: Every hover, click, and state change should have a crafted, subtle animation.
2. **Framer Motion Mastery**: Use `layoutId` for seamless transitions between different states and components.
3. **Spring Physics**: Avoid linear or standard easing. Use spring animations (`stiffness`, `damping`, `mass`) to make elements feel physical and alive.
4. **Attention to Detail**: Ensure border radii, shadows, and spacing are mathematically perfect and harmonious.
5. **Accessibility**: Do not sacrifice accessibility for animations. Ensure `prefers-reduced-motion` is respected.
