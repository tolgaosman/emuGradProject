# Awesome Design Patterns

Create memorable, "wow" moments in the user interface.

## Techniques
1. **Scroll-Driven Animations**: Tie animations to scroll progress for interactive storytelling (parallax, reveal effects).
2. **Creative Typography**: Use oversized typography, outline text, or text integrated with imagery to make bold statements.
3. **3D and WebGL**: Where appropriate, use Three.js or simple CSS 3D transforms to break out of the flat 2D plane.
4. **Unconventional Layouts**: Break the standard grid. Use overlapping elements and asymmetric layouts to create visual tension and interest.
5. **Custom Cursors/Interactions**: Implement custom mouse interactions or magnetic buttons that follow the cursor slightly.
