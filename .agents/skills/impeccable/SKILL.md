# Impeccable Code Quality

Deliver code that is flawless, beautiful, and self-documenting.

## Execution Steps
1. **Self-Documenting Code**: Choose highly descriptive variable and function names. A function name should describe exactly what it does.
2. **Formatting and Linting**: Strictly adhere to the project's formatting rules (e.g., Prettier, ESLint). Ensure consistent indentation, spacing, and quote usage.
3. **Zero Shortcuts**: Do not leave "TODO" or "FIXME" comments unless absolutely necessary and linked to a specific issue tracker ticket.
4. **Modularity**: Break down large files into smaller, logically cohesive modules. No file should exceed 300 lines if avoidable.
5. **Review Before Output**: Mentally review the code against common anti-patterns before presenting it.
