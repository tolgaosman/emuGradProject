# Architectural and Design Taste

Taste is about choosing the most elegant, simple, and satisfying solution to a problem.

## Guidelines
1. **API Elegance**: Design component and function APIs that are intuitive, require minimal boilerplate to use, and have sensible defaults.
2. **Visual Restraint**: In UI, apply restraint. Favor ample whitespace, clear typography, and subtle visual cues over noisy, crowded interfaces.
3. **Minimal Dependencies**: Only introduce third-party libraries when the value heavily outweighs the cost of maintenance and bundle size.
4. **Symmetry and Balance**: Ensure symmetry in code structure (e.g., if there is a `start` method, there should be a `stop` method).
5. **User-Centric Empathy**: Always consider how the end-user (or developer consuming the code) will feel using the product. Reduce friction at every step.
