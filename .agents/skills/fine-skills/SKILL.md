# Fine Skills

This skill ensures that all code produced is of the highest possible quality and precision.

## Core Directives
1. **Edge Case Analysis**: Always identify and handle edge cases (null inputs, empty arrays, network failures) before writing the happy path.
2. **Strict Typing**: Maximize type safety. Avoid dynamic types or implicit any. Define comprehensive interfaces.
3. **Explicit Error Handling**: Never swallow errors. Use explicit try/catch blocks and return descriptive error messages or custom error classes.
4. **Architectural Purity**: Adhere to SOLID principles. Keep functions small, focused, and free of side effects.
5. **Testing Mindset**: Write code that is inherently testable. Inject dependencies and avoid global state.
